# 极简英文 · 读与记 (Minimal English Reader)

专为喜欢纯粹阅读、不希望被复杂算法和社交打扰的学习者打造的手机端极简英文阅读与生词集应用。

---

## ✨ 核心特色（绝无多余功能）

1. **只有两件事：你的文章 + 你的生词**
   - 没有艾宾浩斯记忆曲线算法打卡、没有金币宠物打卡、没有繁琐的分级题库。
   - 纯粹存储、排版和沉浸式阅读属于你的英文文章。

2. **手机端专属交互（点词即查、即存、即发音）**
   - 阅读文章时，轻点任意单词，即刻弹出底栏：
     - 美音地道发音（调用设备原生语音，流畅零延迟）。
     - 国际音标、自动中文简释与英英释义（亦可点击随时手动修改成你的专属记忆笔记）。
     - 一键加入生词本。
   - **文章实时联动高亮**：加入生词本后，该单词在文章中会自动以极简暖色高亮/下划线标注；再次阅读时重点一目了然。

3. **双向联动的生词本**
   - 集中展示所有生词，自动抓取该生词在文章中的**原句上下文**。
   - 点击生词卡片底部的「来源文章」，瞬间跳回对应文章并定位。
   - 支持搜索、按文章筛选、一键标记「掌握/重学」或删除。

4. **精致排版与护眼模式**
   - 提供「暖阳纸」、「极简白」、「夜间黑」三种精心调配的色彩方案。
   - 支持自由切换「优雅衬线体」与「现代无衬线体」，字号大小随心缩放。

5. **100% 隐私安全与离线可用（PWA）**
   - 数据完全保存在手机本地（LocalStorage），无云端泄露风险，无网络时照样流畅阅读。
   - 支持一键导出 JSON 备份，换手机或迁移数据只需一秒导入。

---

## 📱 手机使用方法

### 方式一：电脑开启局域网共享，手机直接连接（最快捷）

1. 在电脑上双击运行 `start.bat`（或在终端执行 `python serve.py`）。
2. 控制台会显示出形如 `http://192.168.x.x:8080` 的网址。
3. 手机连接与电脑相同的 Wi-Fi，在手机浏览器中输入该网址即可打开！
4. **【核心步骤】添加到手机主屏幕，化身原生 App**：
   - **iPhone (Safari)**：点击屏幕底部的「分享」图标 ➔ 向上滑动找到「添加到主屏幕」。
   - **Android (Chrome/Edge)**：点击右上角菜单 ➔ 选择「添加到主屏幕」或「安装应用」。
   - 桌面将生成精美图标，打开后全屏无任何浏览器地址栏，与原生 App 无异！

### 方式二：部署到 GitHub Pages / Vercel（随身永久免开电脑）

因为本项目是纯粹的轻量静态网页（HTML + CSS + JS），你可以将这个文件夹推送到 GitHub 仓库并开启 **GitHub Pages**，或直接将文件夹拖拽上传至 **Cloudflare Pages / Vercel**，就能获得一个永久有效的 `https://...` 专属网址，无论在公司、地铁还是出门在外，手机随时打开使用。
